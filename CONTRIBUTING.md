# Contributing

Thanks for helping improve AI Usage Tracker.

## Setup

1. Clone the repository.
2. Install dependencies with `npm install`.
3. Run tests with `npm test`.

## Guidelines

- Keep the public API stable when possible.
- Add or update tests for behavior changes.
- Preserve the privacy-first behavior: do not collect prompts, responses, or API keys.
- Keep documentation in sync with code changes.

## Release workflow

- Update `CHANGELOG.md`.
- Verify `README.md` examples.
- Run the full test suite.
- Confirm the npm package contents before publishing.
